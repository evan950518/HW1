# 抽樣分配模擬（SQC HW1）

以 C++ 模擬驗證兩個抽樣分配定理，並用互動網頁展示結果：

- **#1-1 中央極限定理**：樣本平均數 X̄ 的抽樣分配隨 n 增加趨近 N(μ, σ²/n)
- **#1-2 樣本變異數的抽樣分配**：常態母體下 (n−1)S²/σ² ~ χ²ₙ₋₁；並以非常態母體作為反例

## 互動網頁

網站位於 [`web/`](web/)，可直接在瀏覽器開啟 `web/index.html`（不需網路、不需伺服器）。

功能：選擇母體分配（離散型／連續型）與參數、以拉桿調整樣本數 n = 1～100、直方圖疊上理論曲線與模擬密度曲線（KDE）、Q-Q 圖、模擬值與理論值對照表、偏態／峰態／KS 距離隨 n 變化的趨勢圖。

## 模擬設計

| 項目 | 設定 |
|---|---|
| 樣本數 n | 1～100（#1-2 為 2～100），每個整數都模擬 |
| 重複次數 R | 10,000 |
| 亂數種子 | 20261016（`std::mt19937_64`，每組題目／參數／n 各自以 `seed_seq` 初始化） |
| 離散型母體 | Bernoulli、Binomial、Poisson |
| 連續型母體 | Normal、Uniform、Exponential、Gamma、Lognormal、t（t 僅用於 #1-2） |

每種分配提供數組預設參數（見 `src/main.cpp` 的 `makeFamilies()`），每一組都完整模擬。

## 檔案結構

```
src/                 C++ 主程式（模擬、統計量計算、輸出）
  main.cpp           模擬流程、參數組、輸出 CSV 與網頁資料
  distributions.hpp  母體分配的參數、理論動差、pdf / pmf
  stats_utils.hpp    動差、直方圖、KDE、KS 距離、常態與卡方分配函數
web/                 互動網頁（只負責讀取與繪圖，所有數字由 C++ 預先算好）
  index.html
  data.js            分配清單、參數組、趨勢圖摘要
  data/{clt,s2}/     每組參數的詳細資料（選到時才載入）
simple/              精簡版：#1-1、#1-2 各自獨立的 C++ 程式，輸出 SVG 圖與 CSV
```

## 重新產生資料

需要支援 C++17 的編譯器（以 MinGW-w64 g++ 11.2 測試）：

```bash
g++ -std=c++17 -O2 -o sim src/main.cpp
./sim                 # 預設 seed = 20261016、R = 10000
./sim 12345 10000     # 自訂 seed 與 R
```

輸出 `web/data.js`、`web/data/` 以及 `output/excel/`（給 Excel 作圖的 CSV）。C++ 標準未規定各分配的抽樣演算法，因此同一個 seed 只保證在同一編譯器下結果相同。
